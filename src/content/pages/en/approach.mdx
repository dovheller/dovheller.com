### Specification

I map the process and define what the system needs to do and how we will verify it.

### Pilot

I build a version we can test in real conditions. For software projects I use coding agents on defined tasks.

### Rollout and handover

I review the changes against the specification, document the rollout, and hand the system to the team that will maintain it.
